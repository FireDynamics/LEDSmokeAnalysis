Side Band Pedestal

Pedestal (additive background) of the LED search areas, estimated in side bands next to the LED strips.

The search area of an LED contains, besides the LED itself, an additive pedestal: stray light, light emitted or scattered by the smoke and noise clipped at 0 after the black level subtraction of raw images. Under dense smoke the LED dims while the pedestal remains, so the plain box sum (sum_col_val) overestimates the transmission. The border ring of the search area (bgsub_sum_col_val) is not suited to measure the pedestal because it lies in the halo of the LED itself. The side bands used here run parallel to the strip, at a distance of typically 25 to 60 px across the strip and over +-R along the strip (R = search_area_radius), so they sample the scene next to the LED but not the LED.

The strip direction is estimated locally for each LED from its nearest neighbours in the same LED array, so vertical, horizontal and oblique strips are supported. Pixels close to any other search area are excluded from the bands, so neighbouring strips do not enter the estimate.

The exclusion is purely geometric and does not know the halo of the LEDs, so for strips closer than the outer band distance and for wide halos the light of a neighbouring strip can still reach the bands and raise the estimated pedestal. Most of that light cancels in the ratio to the reference image, because it is LED light and dims with the same transmission as the LED itself; what remains is a bias only if the two strips lie at different depths in the smoke, which is removed by raising sideband_exclusion_margin above the visible halo.

ledsa.data_extraction.sideband_background.build_sideband_pixels(search_areas: ndarray, directions: ndarray, img_shape: Tuple[int, int], search_area_radius: int, distances: Tuple[float, float] = (25, 60), exclusion_margin: int | None = None) → List[Tuple[ndarray, ndarray] | None][source]

Determine the pixels of the two side bands of each LED.

With t the coordinate along the strip and s the coordinate across the strip, both relative to the center of the search area, a pixel belongs to the side bands if -R <= t < R and lo <= abs(s) < hi (with the same half-open convention as the search area, i.e. lo <= s < hi or -hi <= s < -lo). For a vertical strip this is rows r-R..r+R-1 and columns c+lo..c+hi-1 and c-hi..c-lo-1. Pixels outside the image and pixels within R + exclusion_margin (Chebyshev distance) of the center of any other search area are excluded.

Parameters:

  • search_areas (np.ndarray) – Array with rows (LED id, pixel row, pixel column), the row index equals the LED id.

  • directions (np.ndarray) – Unit vectors along the strip per LED, see estimate_strip_directions.

  • img_shape (tuple[int, int]) – Shape of the image.

  • search_area_radius (int) – Radius R of the search areas.

  • distances (tuple[float, float]) – Inner and outer distance (lo, hi) of the side bands across the strip in pixels.

  • exclusion_margin (int or None) – Margin added to R for the exclusion of other search areas. Defaults to R.

Returns:

Per LED id a tuple of row and column indices of the side band pixels, None if the strip direction of the LED is unknown.

Return type:

list[tuple[np.ndarray, np.ndarray] or None]

ledsa.data_extraction.sideband_background.estimate_sideband_background(data: ndarray, channel_mask: ndarray | None, sideband_pixels: Tuple[ndarray, ndarray] | None) → float[source]

Estimate the pedestal per channel pixel as the mean over the channel pixels in the side bands.

Pixels of the channel with value 0 are included: the black level subtraction clips noise at 0 and the box sum contains these clipped pixels in the same way, so the mean is the matching estimator for the pedestal in the box. Foreign Bayer channels are excluded via the channel mask, not via the pixel value.

Parameters:

  • data (np.ndarray) – Channel array of the image.

  • channel_mask (np.ndarray or None) – Boolean mask of the channel pixels, None if all pixels belong to the channel.

  • sideband_pixels (tuple[np.ndarray, np.ndarray] or None) – Row and column indices of the side band pixels of the LED.

Returns:

Mean pedestal per channel pixel, NaN if the side bands contain no channel pixel.

Return type:

float

ledsa.data_extraction.sideband_background.estimate_strip_directions(search_areas: ndarray, led_arrays: Sequence[Sequence[int]], num_neighbours: int = 4) → ndarray[source]

Estimate the local direction of the LED strip at each LED from its nearest neighbours in the same LED array.

The direction is the principal axis of the positions of the LED and its num_neighbours nearest neighbours of the same array. It is oriented such that the row component is positive (or, for horizontal strips, the column component).

Parameters:

  • search_areas (np.ndarray) – Array with rows (LED id, pixel row, pixel column), the row index equals the LED id.

  • led_arrays (Sequence[Sequence[int]]) – LED ids of each LED array.

  • num_neighbours (int) – Number of neighbours used to estimate the direction.

Returns:

Array of shape (number of LEDs, 2) with the unit vector (row, column) along the strip, NaN for LEDs that are not part of an array with at least two LEDs.

Return type:

np.ndarray

ledsa.data_extraction.sideband_background.subtract_pedestal(sum_color_value: float, pedestal: float, floor: float = None) → float[source]

Subtract the pedestal N * B from the box sum S, with the optional lower limit max(S - N * B, floor * S).

Without the lower limit the optical depth would be unbounded where the LED signal vanishes in the pedestal; values where the limit applies carry no information on the extinction and should be treated as invalid.

Parameters:

  • sum_color_value (float) – Box sum S.

  • pedestal (float) – Pedestal N * B of the box.

  • floor (float) – Lower limit as fraction of S.

Returns:

Pedestal corrected box sum, NaN if the pedestal is NaN.

Return type:

float
